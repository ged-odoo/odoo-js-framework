Generic components

A component whose content is somebody else's: slots.

ThenThe Odoo JS framework, and the dashboard

Slots

Content the caller writes

  • A Card draws the frame. What goes inside is different at every call site.
  • Props pass data down: a string, a number, a record. They cannot pass a paragraph and a button with a handler on it.

root.xml — what we want to be able to write

<t t-name="tutorial.Root">
    <Card>
        <p>Some quick example text.</p>
        <a class="btn btn-primary"
           t-on-click="this.goSomewhere">
          Go somewhere
        </a>
    </Card>
</t>
  • MarkupA paragraph, a button, another component — whatever this screen needs.
  • Its ownthis.goSomewhere is the Root's method. The Card never hears about it.
  • Every callThe next <Card/> holds something else entirely.

Owl calls that a slot: the generic component leaves a hole, and whoever uses it fills the hole.

Slots

A slot is a hole in a template

  • The generic component says where the content goes, with t-call-slot. The caller says what it is.

card.xml — the generic component

<t t-name="tutorial.Card">
    <div class="card">
        <div class="card-body">
            <t t-call-slot="default"/>
        </div>
    </div>
</t>
  • defaultEverything the caller wrote between <Card> and </Card>.
  • Nothing elseThe Card is seven lines of markup, and no javascript at all.
  • ReusableEvery screen that needs a card frame now has one.

The content is rendered where it was written: this.goSomewhere is the Root's method, not the Card's.

Slots

Named slots, and optional ones

  • t-set-slot names a piece of content. Everything left over is the default slot.
  • What the caller gave you is readable: this.props.slots, keyed by slot name.

card.xml

<t t-name="tutorial.Card">
  <div class="card">
    <div class="card-body">
      <h5 class="card-title"
          t-if="this.props.slots.title">
        <t t-call-slot="title"/>
      </h5>
      <t t-call-slot="default"/>
    </div>
  </div>
</t>

root.xml

<Card>
    <t t-set-slot="title">Card title</t>
    <p>Some quick example text.</p>
</Card>

<!-- no title given: the h5 is not
     rendered at all -->
<Card>
    <p>Just a body.</p>
</Card>

A slot can carry a default too: <t t-call-slot="title">Untitled</t> renders that when the caller gave nothing.
