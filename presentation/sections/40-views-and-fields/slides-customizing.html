Customizing views and fields

Changing what a standard field or view does, without forking it.

ThenDental Practice, then Customizing

Customizing views

Two strategies: monkey-patching, or subclassing.

Customizing views

Which one, and when

  • Monkey-patching

    Modify in place. Every instance of that view or field changes, everywhere in the web client, for every user.

  • Subclassing

    Create a variation, and use it on the screens that asked for it: a js_class on the view, a widget on the field.

Subclass when you can: what you add is opt-in, and the standard behaviour is still there for everyone who did not ask.

Fields

Subclassing a field

Extend the component, extend its props, change what needs changing.

hidden_hash_field.js

class HiddenHashField extends HashField {
    props = useProps({
        ...hashFieldProps,
        isHidden: t.boolean().optional(),
    });
}

const hiddenHashField = {
    ...hashField,
    component: HiddenHashField,
    extractProps(fieldInfo) {
        const props = hashField.extractProps(fieldInfo);
        props.isHidden = fieldInfo.options.should_hide;
        return props;
    },
};

registry.category("fields").add("hidden-hash", hiddenHashField);

hidden_hash_field.xml

<t t-name="web.HiddenHashField" t-inherit="web.HashField">
    <xpath expr="//span" position="replace">
        <t t-set="hash"
           t-value="this.props.record.data[this.props.name]"/>
        <span t-if="this.props.isHidden"
              t-out="'*'.repeat(hash.length)"/>
        <span t-else="" t-out="hash"/>
    </xpath>
</t>

<field name="passkey" widget="hash" options="{ 'should_hide': True, 'hash_length': 30 }"/>

Customizing views

Subclassing, with js_class

Register a new view under a name, and use it with the js_class attribute.

class CrmFormRecord extends formView.Model.Record {
    async _save() {
        // custom behaviour before saving, e.g. a rainbowman
    }
}

class CrmFormModel extends formView.Model {
    static Record = CrmFormRecord;
}

registry.category("views").add("crm_form", {
    ...formView,
    Model: CrmFormModel,
});

<form class="o_lead_opportunity_form" js_class="crm_form">
